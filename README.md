# 🛍️ Katalog Produk Responsif

Website katalog produk sederhana yang dibuat untuk tugas **Pemrograman Web Pertemuan 3**.

Website ini menampilkan beberapa produk elektronik dengan desain yang **responsif**, sehingga tampilan dapat menyesuaikan ukuran layar desktop, tablet, dan mobile.

## 📌 Tentang Project

Project ini dibuat dengan konsep dasar HTML dan CSS agar mudah dipahami oleh programmer pemula.

### Teknologi yang digunakan

- HTML5
- CSS3

Tidak menggunakan JavaScript, database, atau framework tambahan.

## ✨ Fitur

- Navbar sederhana
- Halaman hero/banner
- Daftar produk dalam bentuk card
- Gambar produk responsif
- Harga dan deskripsi setiap produk
- Tombol "Lihat Produk"
- Layout menggunakan CSS Grid
- Tampilan responsive untuk desktop, tablet, dan mobile
- Footer sederhana

## 🎯 Tujuan Project

Tujuan pembuatan website ini adalah untuk memahami:

- Struktur dasar HTML
- Penggunaan CSS
- CSS Grid
- Responsive Web Design
- Media Query
- Pembuatan card produk
- Pengaturan gambar agar responsif
- Pengelolaan project menggunakan Git dan GitHub

## 🚀 Cara Menjalankan

1. Download atau clone repository.
2. Buka folder project.
3. Buka file `index.html` menggunakan browser.

Atau jalankan menggunakan **Live Server** di Visual Studio Code.
